# 🏥 Clinical Management System

Sistema web desarrollado para apoyar la gestión administrativa de una clínica, incluyendo pacientes, médicos, citas, servicios, pagos, recibos y reportes.

> Este repositorio corresponde a una versión de demostración para portafolio.  
> No contiene información real de pacientes, credenciales ni datos privados de producción.

## 🚀 Tecnologías

- PHP
- Laravel
- MySQL
- JavaScript
- HTML / CSS
- Git
- DomPDF
- Laravel Breeze
- Spatie Permission

## 📌 Funcionalidades principales

- Gestión de pacientes
- Gestión de médicos
- Administración de servicios y precios
- Control de citas
- Gestión de turnos y espera
- Generación de recibos en PDF
- Registro de pagos
- Control de comisiones médicas
- Reportes diarios y mensuales
- Gestión de usuarios y roles
- Auditoría de acciones
- Dashboard administrativo

## 🧩 Módulos

### Pacientes
Registro y administración de información de pacientes.

### Médicos
Control de médicos, especialidades y comisiones.

### Citas
Gestión de citas con estados como:

- Programada
- En espera
- Realizada
- Cancelada

### Servicios
Administración de estudios y precios según tipo de paciente o institución.

### Pagos y recibos
Registro de pagos y generación de recibos en PDF.

### Reportes
Generación de reportes de ingresos, cierres diarios y actividad por médico.

### Usuarios y permisos
Control de acceso mediante roles y permisos.
